//Dual-surface architecture

One binary. Two surfaces. The wall is gone.

Codex keeps its browser and computer runtimes behind the desktop app. The bridge speaks their native protocols directly, so Claude Code and every other MCP client can reach both — with the host's own configuration, permissions and cleanup semantics preserved.

--surface computer Opt-in

Native Computer Use,
unlocked for everyone.

The installed Codex cua_repl service is a stateful JavaScript runtime for desktop windows and browser tabs alike. The bridge discovers it, relays it, and cleans it up.

// one Target interface, two worlds const wins = await cua.listWindows(); const app = await cua.getApp({ windowId: wins[0].windowId }); const state = await app.getAXStateAndScreenshot(); await app.click(state.elements[0].index); await app.typeText("hello from the bridge");
  • Connects any MCP agent or shell script to Codex's installed cua_repl (@oai/cua + @oai/sky + @oai/browser-desktop).
  • Unified cua Target API: listWindows, getApp({windowId}), launch_app(), listBrowsers, getTab(), shared getAXStateAndScreenshot, click(elementIndex | [x,y]), drag, scroll, pressKey and typeText.
  • Full-duplex, cancel-safe JSON-RPC stdio relay with bidirectional elicitation/create application approval passthrough.
  • turn_ended execution-context cleanup, then Windows Job Object / Unix process-group teardown. Timed-out calls are never replayed.
  • Preserves the host launch row: env, env_vars, timeouts, enabled_tools and disabled_tools — the bridge never rewrites your config.

Observe, locate, capture — with no replay

Arm observation before the action so early events are not lost. Locators compose declaratively; a dispatched input is never retried behind your back. Same tab, three JSONL steps.

codex-browser-bridge batchjsonl 
// 1 · observe before acting: frames, dialogs, events, logs, explicit gaps
{"name":"codex_observe","arguments":{"tab_id":42,"action":"start","wait_until":"networkidle"}}

// 2 · declarative locator: role + accessible name, composed with has_text
{"name":"codex_locator","arguments":{"tab_id":42,"action":"click","role":"link","name":"Invoices","has_text":{"regex":"^Invoices"}}}

// 3 · capture one element with structural metadata
{"name":"codex_screenshot_element","arguments":{"tab_id":42,"selector":"#invoice-total","include_info":true}}
!Use --profile basic (46 tools) when context is tight, network (65) for cookies and CDP, full (66) by default in the plugin. Tabs are owned per session and released on turn end.

//Trust model

Thin adapter. Hard boundaries.

This binary holds the keys to a logged-in browser and a desktop session. Every design choice assumes that.

No profile copy, no second extension

The bridge is a client of the transports your extension already opened. A pipe name is transport metadata; the extension instance ID is identity.

Bounded by default

Text and image byte budgets with explicit truncation markers. Oversized screenshots return a summary, never partial base64.

Never replay input

A timeout is an unknown outcome, not a retry token. Inspect the page, then decide. Pointer moves and scrolls are dispatched once.

Deterministic cleanup

EOF, SIGINT and SIGTERM cancel in-flight work, send turn_ended, close stdin, then tear down the owned process tree — Job Object on Windows.

Dual-era MCP

Legacy initialize negotiation from 2024-11-05 through 2025-11-25, plus stateless 2026-07-28 with server/discover, resultType and cache hints.

Local-only by design

No network port, no telemetry, no hidden fallback runtime. Raw CDP is an allowlisted diagnostic escape hatch, not a second control plane.
